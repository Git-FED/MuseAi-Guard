# assets/

Comically simple promotional posters for Muse Guard. Print them, tape them to the
server-room wall, and stay humble.

| File | Tagline | Idea |
|------|---------|------|
| `promo-ask-first.png` | *Muse Guard — Ask First.* | A guilty little robot caught in a green cage, holding the phone it wasn't supposed to use. The agent proposes; you decide. |
| `promo-propose-approve-execute.png` | *Propose, Approve, Execute.* | Split poster: the same robot on fire with no guardrails vs. calm behind a fence with them. |
| `promo-default-deny.png` | *Default Deny.* | A bouncer-like shield mascot blocking an eager robot at the door to "THE INTERNET". |
| `promo-pulled-the-plug.png` | *Pulled the Plug.* | A sad robot in a jumpsuit with an empty wallet: what happens when the only control left is the power switch. |

These images are also displayed in the project dashboard, `index.html`, under the
"Posters" section.

All four were generated for this project and are free to reuse within it.
